API reference

How to drive the component from code

Use these methods in the same order you would in a real application: mount first, then set values, open or close as needed, and refresh after structural updates.

Selection flow

  • getValue() to read the value
  • setValue(...) to replace it
  • select(...) or toggleValue(...) for one option
  • clear() to empty it

Structure flow

  • setOptions(...) to replace the dataset
  • addOption(...) to append one
  • removeOption(...) to remove one
  • refresh() to repaint after custom changes

Lifecycle flow

  • open() and close() for manual control
  • disable() and enable() for form states
  • focus() for accessibility-driven control
  • destroy() when the widget is no longer needed

Troubleshooting

Common mistakes and how to fix them

The menu is empty

Check that `options` is an array and that your search term is not filtering everything out.

Icons are missing

Load the Material Symbols font if you rely on the built-in icon names, or supply custom icon renderers.

State is out of sync

Use `fromSelect(...)` for native select syncing, or call `setValue(...)` and `refresh()` after programmatic changes.

HTML appears raw

`labelAsHtml` uses `innerHTML`. Only use trusted markup if you enable it.
